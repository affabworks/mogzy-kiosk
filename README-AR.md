# تشغيل Mogzy على التابلت

## 1) قاعدة البيانات (مرة واحدة)
1. في Supabase افتح **SQL Editor** وشغّل `patch1.sql` (فيه ربط التسجيل بالحضور تلقائياً). لازم يظهر Success.
2. من **Authentication > Users > Add user** أنشئ حسابك (بريد + كلمة سر + Auto Confirm).
3. افتح `bootstrap.sql`، بدّل `PUT-YOUR-EMAIL-HERE` ببريدك، وشغّله. هذا ينشئ شركة Woods وحساب المالك وموظفين تجريبيين.

## 2) الوظيفة السحابية
1. **Edge Functions > Deploy a new function > Via Editor**.
2. الاسم: `kiosk` (بالضبط).
3. امسح الكود الموجود والصق محتوى `supabase/functions/kiosk/index.ts`.
4. **أطفئ خيار Verify JWT** (في إعدادات الوظيفة)، لأن الجهاز يدخل بمفتاحه الخاص. ثم Deploy.

## 3) رفع الموقع (لازم HTTPS عشان الكاميرا)
أسهل طريقة GitHub Pages:
1. أنشئ مستودعاً جديداً على GitHub باسم `mogzy-kiosk`.
2. ارفع محتويات هذا المجلد (index.html, app.js, config.js, sw.js, manifest.json, logo.png, lib/, models/).
3. Settings > Pages > Branch: main > Save. الرابط يظهر بعد دقيقة.

## 4) ربط التابلت
1. افتح الرابط في كروم على التابلت واسمح بالكاميرا.
2. شاشة "ربط هذا الجهاز": سجّل بالبريد وكلمة السر. الجهاز يتسجل ويتحفظ.
3. أول مرة يحمّل النموذج (حوالي 7 ميجا) وبعدها يشتغل بدون إنترنت.
4. من قائمة كروم: **Add to Home screen** ثم افتحه من الأيقونة بملء الشاشة.

## 5) تسجيل وجوه الموظفين
1. اضغط على لوجو Mogzy **ثانيتين** (مخفي).
2. سجّل دخول المدير، اختر الموظف، أكّد وجود الموافقة المكتوبة، والتقط 3 صور (مواجهة، يمين، يسار)، ثم **حفظ الوجه**.

## ملاحظات مهمة
- اتجاه "اليمين/اليسار" في الاختبار يُجرَّب على التابلت الحقيقي أول مرة. لو طلع معكوساً قل لي.
- التحقق بتحريك الرأس يمنع الصورة الثابتة، لكنه لا يمنع فيديو مسجّل. لاحقاً نضيف طبقات أقوى.
- الموافقة المكتوبة من الموظف مطلوبة قانونياً قبل تسجيل وجهه (قانون 151 لسنة 2020).
